# Double Inverted Pendulum — Control in the Browser

A double inverted pendulum on a cart, swung up from hanging and balanced in the
upright **up-up position**. LQR state feedback from an exact Riccati solution,
swing-up by iLQR trajectory optimisation, tracked by a time-varying LQR — all
in plain JavaScript, no libraries, in real time.

Open [`index.html`](index.html) in a browser and press **Power**.
